Greek script diacritical combinations

This list of combinations is compiled for Greek support by the Gentium font. For a greater amount of test-cases and less common combinations, confer the similar list from the TITUS project with 457 combinations. Install the fonts Gentium and SBL Greek for the intended display of this page.

This list covers the few polytonic combinations with the breve that I was able to actually attest in printed pubblications, though a complete support as was made for the macron in v7 is preferrable over only these few attested forms. This kind of support is already present in the fonts SBL Greek and Brill. All possible combinations include alpha|iota|upsilon|Alpha|Iota|Upsilon + breve + [rough|smooth] + [acute|grave] for a total of 48 potential new precomposed forms.

The list also gives attestations for requesting a properly placed anchor below the iota, to allow for its semivocalic value, the lack of which in Gentium was also lamented in this forum thread. This is used in various Demotic texts, appearing variously as an inverted breve (032F), a tilde (0330) or straight line (0331). In print text, the iota is also rotated 180° whenever this diacritic is added. Though it is generally omitted in digitisation, it can be contrastive, and needs to be properly transcribed. A Unicode proposal (Haralambous 2002: § 3.2, pp. 18–19) was made to include both this letter as a precomposed character and another one for the upsilon. The proposal failed. I have never personally encountered the reversed upsilon, so it must not be as common. (From the Unicode mailing list, in 1999, Diamantidis proposed to encode this simply as iota + combining breve below, see mail.) Granted that this is an issue which may need more investigation, I think the best action as of now is to add the anchor below the iota. The inverted breve below the iota is also used by etymological works of Ancient Greek when reconstructing pre-written forms as well as in Aromanian (in these cases the iota is never found rotated), and in both cases it is extremely contrastive and cannot be overlooked.

This list also includes other miscellaneous obscure combinations found in various text unsupported as of Gentium v7, and gives images for the double-breves sequences (035C and 1DFC) whose marks could be raised or the positioning adjusted in some other way.
